tik.maya
========

**tik.maya** is a modern, namespaced Pythonic wrapper for ``maya.cmds``. It serves
as the foundation for all TikWorks tools and frameworks, bringing type safety,
object-oriented design, and robust node tracking to Maya scripting.

.. note::
   tik.maya is under active development. The API may evolve as features land.
