THE SHELL
Every tab is the same interaction: a set of states you pick from, one click, and the rig does not move.
That is what makes one tool out of three. A switch changes what a control does — which point it turns about, which chain drives it, whether the elbow is held — and the animator's pose survives it. Anything that moves the rig belongs somewhere else.

1  TAB STRIP
One tab per family of switch. A lit dot means the current selection can use it.
2  SELECTION CONTEXT
Always the same shape, always second. Side colour, control name, module. This is what makes the tool non-modal — it reads the viewport instead of blocking it.
3  STATE PICKER
The only part that differs per tab, and only in its labels: presets, IK/FK, free/pinned. One click applies.
4  SHARED ACTION BAR
Concerns every switch has: whether to key, which frames, and what just happened. Written once, not three times.

A fourth tab earns its place by fitting that table — a named set of states, a match step, and something it promises not to disturb. If it cannot fill the last column it is not a switch, and it does not belong here.
